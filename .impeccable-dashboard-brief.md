# Dashboard surface brief

## Scope

Authenticated dashboard for a role-aware task management application. Mode: Operate.

## Audience and job

Government and organization staff need to understand their current operational scope quickly and move into tasks, pipelines, teams, or administration.

## Direction contract

THESIS: A calm public-service operations desk that makes role, scope, and next work legible at a glance; it refuses the generic KPI wall.

OWN-WORLD: A light paper workspace anchored by deep ink navigation, restrained cobalt actions, a small amber status signal, squared 8px geometry, clear rules, and tabular operational numerals. Components should feel like a well-maintained government service console: direct, durable, and quiet.

STORY: The visitor understands where they are, what operational scope they hold, and which work areas deserve attention. They move from the dashboard into a relevant queue using the existing navigation.

FIRST VIEWPORT: A compact title block with role context sits above one wide status strip and a responsive two-column work overview. The role and current scope appear before the metric grid; empty values remain clearly marked as pending data rather than disguised as zeros.

FORM: Code-led dashboard redesign using the existing Angular Material shell and permission-aware navigation; seed key: civic-operations-desk.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Unresolved decisions

Live dashboard data and organization-specific naming remain outside this UI pass because the current repository exposes placeholders only.
